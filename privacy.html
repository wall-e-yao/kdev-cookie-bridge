1. 用途与范围

KS Cookie Bridge 为配套研发网页提供 Cookie 查询能力。匹配页面通过 window.getCookies(url, domain) 查询 kuaishou.com、gifshow.com 及其子域和 localhost 的 Cookie。扩展需要配套网页、相应平台账号和网络条件，不是独立的研发平台。

本政策说明扩展自身的数据访问和交付。Cookie 返回网页后，该页面及其运营方的进一步处理还受该网站适用的隐私政策约束。请只在信任的页面和脚本环境中使用。

2. 访问的数据

扩展处理请求中的目标 URL、域名，以及 Chrome Cookie API 返回的 Cookie 名称、值、所属域、路径、有效期、Secure、HttpOnly、SameSite 等属性。Cookie 值可能包含登录会话、认证凭证、账号标识、偏好设置或其他网站保存的信息。

查询受 Chrome 主机权限限制，仅涉及 kuaishou.com、gifshow.com 及其子域和 localhost。localhost 用于本地配套页面与开发调试，不自动包含 127.0.0.1 或其他回环地址。当前版本不按具体 Cookie 名称过滤结果。

扩展没有调用浏览历史 API，也没有专门记录鼠标、键盘、滚动、页面正文或通信内容的功能。Cookie 本身仍可能包含个人数据，不应被视为不敏感信息。

3. 查询发生的时机

安装并启用后，桥接脚本在匹配的 kuaishou.com、gifshow.com 及其子域和 localhost 页面加载。页面通过查询接口发起请求时，扩展才执行 Cookie 查询。当前版本没有每次查询的额外确认弹窗，匹配页面中的脚本能够发起请求。

扩展使用结果完成已披露的查询与返回功能。扩展代码不调用 Cookie 写入或删除 API。

4. 数据流向与接收方

查询结果经扩展后台、内容脚本和页面 DOM 桥接，返回发起请求的匹配页面。该页面及其中运行的脚本能够接触查询结果；页面及其运营方是结果的接收方。桥接中的 Base64 仅用于编码，不提供加密保护。

扩展自身不包含独立数据上传接口、分析 SDK、广告 SDK 或开发者数据接收服务。开发者不通过扩展内置的独立服务接收 Cookie。

接收页面可能继续使用、传输或保存结果。扩展不会控制该页面后续的网络请求、日志或保存行为，因此本政策不作“网页不上传”“网页不保存”或“所有数据只在本地处理”的承诺。请先阅读配套网站的数据处理说明；无法确认时，请勿在该页面启用扩展访问。

5. 保存期限

扩展代码不将查询结果写入扩展持久化存储、文件或数据库，也不维护保存结果的开发者服务器。请求结果在浏览器内存及通信节点中处理，完成的通信子节点会被移除。

移除节点不等于撤回页面已获取的数据，页面脚本可能仍保留结果。配套网页、服务器、日志及备份的保存期限由对应网站的政策与实现决定，扩展无法代替其运营方删除数据。

6. 停止访问与删除

你可以通过 Chrome 扩展管理界面限制站点访问、停用或卸载扩展，以停止后续访问。限制权限可能使配套功能不可用。

停用或卸载不会自动清除网站已有 Cookie，也不会删除此前已返回页面的数据。你可以在 Chrome 站点数据设置中清除相应 Cookie，这可能使网站退出登录。页面或服务端已保存的数据，应向对应网站运营方申请处理。扩展相关问题可联系上述邮箱。

7. 安全与用途限制

认证 Cookie 可能使接收方获得相应会话能力。请只在信任的页面和设备上启用扩展，不在公开问题、截图、日志或反馈中提供真实 Cookie。当前版本没有逐个来源的额外确认机制，站点访问权限不等于对页面所有脚本的独立信任判断。

本扩展仅为上述 Cookie 桥接用途处理和交付数据，不包含出售数据、广告定向、信用度判断或贷款功能，不为与单一用途无关的目的使用或转移数据。本扩展对用户数据的使用与转移遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。
