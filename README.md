# KS Cookie Bridge

为配套研发页面提供 `kuaishou.com`、`gifshow.com` 及其子域和 `localhost` 的 Cookie 查询能力。当前本地包版本：**1.0.2**。

本仓库保存公开说明、隐私政策与 Chrome Web Store 素材，不包含扩展源码或真实 Cookie。

- [隐私政策网页](https://wall-e-yao.github.io/kdev-cookie-bridge/privacy.html)
- [隐私政策 Markdown](PRIVACY.md)
- [商店隐私字段说明](STORE-PRIVACY.md)
- 支持：yaohao971112@gmail.com

## 使用与限制

需要配套研发页面及相应账号、网络条件。匹配页面中的脚本能够请求 Cookie，当前无逐次确认弹窗或 Cookie 名称过滤。请只在信任的页面启用访问。

扩展自身不写入或删除 Cookie，不内置独立上传服务。返回网页后的传输与保存方式请查看对应网站政策。
